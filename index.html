Fathzer

Open source applications, simulators and libraries. Web apps are hosted on GitHub Pages.

Applications & libraries

  • Mon Patrimoine

    A free wealth-tracking application: it estimates the net value of your assets after taxes, keeps a full history of your investments, and shows constant-euro values (INSEE price indices). Your data stays in your own cloud storage.

    Designed exclusively for users subject to French taxation — all calculations rely on French tax rules, and the app itself is in French.

    Application GitHub

  • Darts Simulator

    A dart throw simulator: pick a target zone and your throwing accuracy, then watch the darts land on the board, with running statistics and expected score.

    Application GitHub

  • Push Swap Simulator

    An interactive visualizer for the push-swap problem: step through operation sequences on two stacks, debug them, and compare two solutions side by side.

    Application GitHub

  • Javaluator

    A Java library that evaluates arithmetic expressions: variables, constants, functions, operators and parentheses. Published as com.fathzer:javaluator.

    Maven Central GitHub
