Quelques applications et simulateurs open source, hébergés sur GitHub Pages.

  • Mon Patrimoine

    Application gratuite de suivi de patrimoine : valeur nette estimée après prélèvements sociaux et impôts, historique des placements, euros constants (indices INSEE). Vos données restent dans votre espace de stockage cloud personnel.

    Application GitHub

  • Darts Simulator

    Simulateur de lancer de fléchettes : réglez la zone visée et la précision du tir, puis observez les impacts sur la cible, les statistiques et l'espérance de gain.

    Application GitHub

  • Push Swap Simulator

    Visualisation interactive du problème push-swap : exécutez pas à pas des séquences d'opérations sur deux piles, déboguez et comparez deux solutions côte à côte.

    Application GitHub
